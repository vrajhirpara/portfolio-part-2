# Activity B30 - AI Image Watermarking and Regeneration Test

1. AI Image Generation

A procedural AI-generated landscape image was created using Python to simulate an AI-generated image.

2. Imperceptible Watermark Embedding

A hidden watermark was embedded into the image using Least Significant Bit (LSB) steganography.

3. Image Regeneration Testing

JPEG compression was used to simulate image regeneration and test watermark robustness.

4. Watermark Detection and Results

The watermark detection process evaluated whether the hidden watermark survived compression and regeneration.
