# Activity B1 - Weak Security Implementations

1. Weak Password Policy
   Weak passwords can be guessed easily by attackers using brute-force attacks.
   Evidence: weak password policy.jpeg

2. No Multi-Factor Authentication (MFA)
   Systems without MFA are less secure because attackers can access accounts using stolen passwords only.
   Evidence: MFA.jpeg

3. Unencrypted Data Storage
   Sensitive data stored in plain text can be viewed easily if attackers gain access to the database.
   Evidence: Unencrypted Data Storage.jpeg

4. Outdated Software Versions
   Using old software with known vulnerabilities can allow attackers to exploit the system.
   Evidence: outdated software.jpeg

5. Poor Input Validation
   Websites that do not properly validate user input may become vulnerable to SQL injection and XSS attacks.
   Evidence: poor input.jpeg
