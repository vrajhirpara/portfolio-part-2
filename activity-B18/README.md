# Activity B18 - Contribute to an Open-Source Cybersecurity Project

1. Windows Digital Forensics Investigation

An open-source cybersecurity project related to Windows digital forensics was explored using GitHub resources and beginner forensic exercises.

2. Forensic Analysis Activities

The project included forensic image creation using FTK Imager, Windows file system analysis using Autopsy, browser artifact investigation, Shellbags analysis, and deleted file recovery.

3. Cybersecurity Learning and Open-Source Participation

The activity improved understanding of forensic investigation techniques, evidence collection, Windows artifacts, and open-source cybersecurity collaboration.
