# Activity B27 - Applying Encryption to a Real-World Problem

A real-world business scenario was used to demonstrate how encryption protects sensitive customer information from unauthorized access.

Customer invoice data was converted from readable plaintext into unreadable ciphertext using AES-256 encryption.
